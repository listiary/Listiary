Ours is a wiki software for nested lists - Listiary with its own markup language Describe Markup that we develop ourselves

Listiary is a php / javascript tool behind the wiki farm listiary.org that is used both to create public cnowledge and manage personal projects like personal knowledge bases, shopping lists and exercise journals for example. It is powered by the Describe markup language - a custom language we developed for the platform, and supports Variety of list types, Tools for working with list - it is also a playground and editor, Extensible via plugins, Bot fed automated pipelines - features that makes it further unique, powerful and valuable tool. We will go over those points next in a bit more details




Listiary is a custom wiki platform for writing lists. It is similar to other wiki platforms in terms of monetization - it is free and open source - but very different in spirit and execution.

Listiary is distributed - kind of like Mastodon - users choose servers and content to be loaded - which makes a huge difference in terms of sustainability and moderation, compared to other, more rigid models.

Listiary is fed by bots - Oracles watch, automated agents post content on PHP staging pools, and curator bots auto-journal data points - like songs played on a radio, weather forecasts or stock prices by timestamp, e.g.

Listiary is a custom platform developed in plain JavaScript and PHP - without dependencies that can introduce security vulnerabilities and maintenance overhead.

Listiary has its own language - Describe. The Describe Markup Language compiler utilizes ANTLR 4 in C#, and is a powerful, flexible, tested and documented tool in its own right.

Listiary is expandable via plugins - people write their own and submit them for approval, and users can choose to add, for example, a radio player stat viewer, to customize their experience.

Listiary will have a flexible monetization model - anyone will be able to use it for free, while paying users will be able to host private wikis on our domain - think GitHub enterprise cloud for example.

And to begin with, lists stick out like a sore thumb on many wiki platforms, because large, wide, awkward lists don't fit neatly inside text, or software templates made for presenting text - but Listiary is tailored toward lists, and lets the complexity shine in elegant and convenient way. You can have checkbox lists, timed lists that change color or text when they expire, and much, much more.

Listiary is also a kind of editor - users can edit, highlight, sort on top of public or their own lists and save versions of their changes as drafts.
